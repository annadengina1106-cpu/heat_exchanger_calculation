# Расчёт кожухотрубчатого теплообменника

Программа на Python для автоматизированного расчёта кожухотрубчатого теплообменника охлаждения бензола. Разработана в рамках профессиональной переподготовки в Уральском федеральном университете (2023).

**Цель проекта:** заменить ручные инженерные расчёты, исключить ошибки при подборе оборудования и ускорить процесс проектирования.

---

## Инструменты и технологии

- Python 3
- Библиотеки: `csv`, `math`, `PIL` (Pillow)
- Среда разработки: PyCharm / Jupyter Notebook

---

## Функциональность программы

- Ввод исходных данных (производительность, температуры)
- Расчёт теплового баланса
- Определение средней движущей силы процесса
- Ориентировочный и уточнённый подбор теплообменника
- Интерполяция теплофизических свойств теплоносителей
- Расчёт коэффициентов теплоотдачи и теплопередачи
- Проверка отклонений температур стенок
- Вывод результатов и выбор оборудования

---

## Как запустить проект

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/ваш_логин/heat_exchanger_calculation.git
   ```

2. Установите библиотеку Pillow:

   ```bash
   pip install pillow
   ```

3. Запустите основной скрипт:

   ```bash
   python heat_exchanger.py
   ```

Все необходимые файлы (CSV с данными и изображение таблицы) лежат в корневой папке.

## Результаты проверки

Программа успешно прошла проверку на реальных данных. Отклонения температур стенок не превышают 5%, что подтверждает корректность расчётов.

**Пример вывода:**

```
Число труб при ориентировочном значении Re = 10000: 71
Ориентировочная расчетная поверхность теплообмена: 21.33 м2
Выбираем ближайший теплообменник с поверхностью, большей, чем расчетная: 36.76 м2
Запас составит: 14.25 %
```
